
🚀 Overview

Flow is designed for students, who want to save time through automation without relying on third-party SaaS tools.


✨ Features

> Check if a website is up

> University tracker application

> Organizes downloads and documents by file type

> Merges multiple PDF files into one

> Compress & resize pictures to make it ready to share it

> Share Wifi Qr Code 

> Converts between CSV and Excel formats interactively

> Let you compress your folder in Documents path
