
🚀 Overview

Flow is designed for professionals and students, who want to save time through automation without relying on third-party SaaS tools.


✨ Core Features

🏢 Job Automation
> Automatically scans job boards or company career pages

> Filters by keywords, location, and posting date

🏠 Property Finder
> Monitors rental listing pages based on location, price, and bedrooms

> Avoids duplicates and logs new listings automatically

🎓 Students
> University tracker application

🗂️ File Utilities
> Organizes downloads and documents by file type

> Merges multiple PDF files into one

> Creates compressed backups with timestamps

📊 Data Tools
> Converts between CSV and Excel formats interactively

> Cleans text files by removing duplicates or empty lines

🧠 Personal Productivity
> Sends scheduled email reminders

> Tracks birthdays and upcoming events
